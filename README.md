# Multedit

Multedit — веб-приложение для совместного редактирования текстовых документов в режиме реального времени. Проект разработан в рамках курсовой работы с использованием нереляционных хранилищ данных и инструментов контейнеризации.

## Выполнение условий курсового проекта
В проекте реализованы и интегрированы следующие технологии:
* Docker Compose используется для контейнеризации и развертывания всех сервисов одной командой.
* Redis применяется в качестве In-Memory хранилища для синхронизации сессий пользователей и кэширования правок.
* Нереляционная база данных используется для гибкого хранения текстов документов и истории изменений.

## Основные возможности
* Одновременное редактирование документов несколькими пользователями.
* Мгновенное отображение изменений у всех участников сессии.
* Автоматическое сохранение документов.

## Запуск проекта локально
1. Клонировать репозиторий:
git clone https://github.com
cd Multedit

2. Запустить контейнеры:
docker-compose up --build
