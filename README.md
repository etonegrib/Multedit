# Multedit — приложение для совместного редактирования текстовых документов

Курсовой проект. Веб-приложение с клиент-серверной архитектурой и синхронизацией
в реальном времени: несколько пользователей одновременно редактируют один
текстовый документ, видят изменения друг друга и общаются в чате.

**Целевая платформа:** Windows / веб-браузер.

---

## Стек технологий

| Слой | Технологии |
|------|------------|
| Backend | Python 3.9+, Django, Django Channels, Daphne (ASGI) |
| Канальный слой | Redis (`channels-redis`) |
| Frontend | HTML + JavaScript (или React) |
| БД | SQLite (по умолчанию, через Django ORM) |

---

## Функционал

- создание и открытие текстового документа;
- совместное редактирование текста в реальном времени через WebSocket;
- отображение курсоров пользователей;
- чат внутри документа;
- сохранение текущего состояния документа в базу данных.

**Ограничение:** используется стратегия **Last Write Wins** (LWW) — при
одновременном вводе в один и тот же фрагмент возможна потеря символов.
Математическое разрешение конфликтов (CRDT/OT) не реализуется.

---

## Требования

- Python 3.9 или выше;
- Redis (через Docker или Memurai — см. ниже);
- браузер (Chrome/Edge).

## Быстрый запуск

1. Установить зависимости:
   pip install -r requirements.txt

2. Запустить Redis:
   docker run -d -p 6379:6379 --name multedit-redis redis:7-alpine

3. Применить миграции:
   python manage.py migrate

4. Запустить сервер:
   python manage.py runserver

5. Открыть http://127.0.0.1:8000/
